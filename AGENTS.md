# Project Instructions

## Language

Always use English for all text written as part of this project, including:

- Code comments and documentation comments.
- Identifiers, such as variable, function, class, and file names.
- Documentation, specifications, and configuration descriptions.
- Commit messages, branch names, and pull or merge request titles and descriptions.
- Test names, assertions, and diagnostic messages.
- Default application UI text, error messages, and logs.

Localized Android resources may use their target language. Keep resource names, code, documentation, and diagnostics in English.

Conversation with the user may remain in the user's preferred language.
