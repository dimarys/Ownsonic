# Screenshots

`music-en.png`, `podcast-en.png`, and `settings-en.png` are unedited captures of Ownsonic's English interface from an Android 14 emulator at 1080 by 2400 pixels. The Settings capture is scrolled to the source and rating options.

The screenshots use fictional song, artist, album, podcast, and episode names and sample server settings. The geometric cover illustrations were created for these screenshots; no third-party music or artwork is included. Demo audio is generated silence. The screenshots and original sample artwork are covered by the project's GPL-3.0-only license.

Capture each screen with the same device size, language, and theme when updating the README images. Keep connection credentials and personal media metadata out of the captures.
