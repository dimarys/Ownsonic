# Ownsonic 1.0

First public release of Ownsonic, an offline Android music and podcast player for Airsonic.

## Features

- Download a selected music playlist and listen without an internet connection.
- Review songs with configurable Like and Dislike ratings, then upload ratings on the next sync.
- Keep a fixed shuffled music queue between synchronizations, with playback position saved locally.
- Download the oldest or newest episodes of a selected podcast, play them chronologically, and mark episodes as heard.
- View embedded music artwork and cached podcast covers offline.
- Use background playback, headset controls, an optional rating reminder, and Wi-Fi-only automatic synchronization.
- Submit eligible naturally completed music listens through Airsonic's Last.fm integration.
- Use the interface in English or Russian.

## Installation

1. Download `Ownsonic-1.0-release.apk` from the assets below.
2. Open the APK on an Android 8.0 or newer phone. If prompted, allow the app used to open the file to install apps from this source.
3. Open Ownsonic, configure your Airsonic server in Settings, select your sources, and synchronize before going offline.

This APK uses the same signing certificate as the previous personal release builds and can update them. A debug build uses a different certificate; upload pending ratings and listens before uninstalling it, since uninstalling clears local app data.

## Notes

- An Airsonic-compatible server and an account with access to the selected media are required.
- Downloads use original server files; supported formats depend on Android's codecs.
- Android may delay scheduled synchronization to satisfy network and battery conditions.
- Downloaded media is stored on the phone. This release contains no music or podcast content.
